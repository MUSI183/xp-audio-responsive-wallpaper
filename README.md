# Windows XP 音频响应 Q 弹人偶壁纸

基于 Wallpaper Engine 网页壁纸（Web + Canvas）。

## 功能
- 音频响应弹簧人偶（大人偶+16个小人偶，可调数量1-32）
- 3D 迪厅球特效（随机散射光束、地面光点、星尘粒子、封面取色）
- 系统媒体信息组件（歌名/歌手/封面/进度条）
- 时间环境系统（清晨/正午/下午/黄昏/夜晚/深夜，含星空流星）
- 人偶自定义图片替换
- 全部参数可在 Wallpaper Engine 右侧属性面板调节

## 使用
1. 安装 Wallpaper Engine
2. 将本项目文件夹放入 wallpaper_engine/projects/myprojects/
3. 在 Wallpaper Engine 中打开即可

## 技术栈
- 原生 HTML/CSS/JS
- Canvas 2D 手动 3D 投影（迪厅球）
- Wallpaper Engine Web API（音频监听、媒体集成、属性面板）
